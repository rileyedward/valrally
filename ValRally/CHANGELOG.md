# Changelog

## 0.2.0

- New Windows launcher, `ValRally-Launcher.exe`, on the GitHub releases page. It finds Valheim through Steam, installs BepInEx, Jotunn and ValRally into its own folder so plain Valheim stays untouched, and has Play, Update and Uninstall buttons. No mod manager needed.
- No changes to the mod itself.

## 0.1.0

First public test build. Targets Valheim 1.0.20, BepInExPack_Valheim 5.4.2351 and Jotunn 2.30.2.

- Drivable rally car with raycast suspension, Pacejka tyres, wheel spin, an automatic gearbox and traction control.
- Chase camera with two presets and a colour filter that fades in while driving.
- Grip, dust and crunch change with the ground under each wheel.
- Rally start, checkpoint and finish pieces with a timer, splits, best times, a ghost and pace notes.
- Console commands for spawning the car, live tuning, surfaces, stages and a scripted handling test.

Handling, surfaces and stages haven't been playtested in game yet.
